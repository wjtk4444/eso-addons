# eso-addons

Addons for The Elder Scrolls Online that I wrote or reworked. Each folder is one addon with its own README.

## Combat

| Addon | |
|---|---|
| [AmIStunned](AmIStunned) | A reliable STUNNED / ROOTED / BLOCKING indicator in the middle of the screen. |
| [ImprovedDeathRecapVanillaUI](ImprovedDeathRecapVanillaUI) | Improved Death Recap's data in the game's own death recap window. |
| [SchrodisTickTracker](SchrodisTickTracker) | Shows when your next stamina regen tick lands, right on the stamina bar. |
| [SkillIssue](SkillIssue) | Blocks chosen skills from being cast: always, in combat or out of combat. |
| [UltimateRegenTimer](UltimateRegenTimer) | Counts down the 8 seconds of passive ultimate generation after a light attack, block or dodge. |

## Groups, dungeons and PvP

| Addon | |
|---|---|
| [AddedInfoUnitFrames](AddedInfoUnitFrames) | Role colors, large frames for groups of up to 12 in a role-sorted grid, class icon and CP. Fork of Added Info - Unit Frames. |
| [DungeonSorter](DungeonSorter) | Sorts the dungeon list in the Activity Finder alphabetically. |
| [DungeonTimerTrial](DungeonTimerTrial) | Adds trials and arenas to Code's Dungeon Timer. |
| [EvenBetterScoreboard](EvenBetterScoreboard) | Battleground scoreboard with damage, healing and class icons, plus multi-queue. |
| [RideAlong](RideAlong) | One keybind to ride a group member's multi-rider mount. |
| [SchrodisWardrobe](SchrodisWardrobe) | Wizard's Wardrobe pages for every Armory build. |
| [Teleport](Teleport) | `/tp` for every kind of travel: zones, dungeons, houses, players, survey maps, quests. |

## Installation

Copy the addon's folder into `Documents/Elder Scrolls Online/live/AddOns/` (create the folder if it doesn't exist) and enable it in the game's AddOns menu. Check the addon's README for libraries it needs; those are on [ESOUI](https://www.esoui.com/) and in Minion.

The `master` branch holds the versions I use myself, but there are no release builds, so a commit can occasionally be broken.

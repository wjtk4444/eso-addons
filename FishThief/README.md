# FishThief

Fishing without the bait juggling:

- **Right bait automatically.** When you look at a fishing hole, the matching bait is selected: lake, saltwater (including mystic and Abecean), river, or foul (also oily and event holes). The rarer bait (minnow, chub, shad, roe) is used first, then the common one (guts, worms, insect parts, crawlers), then simple bait. The order can be changed in the settings.
- **You know when a fish bites.** A sound plays and the interaction prompt turns green until you reel in.
- **Out of bait?** Optionally, the prompt says "No appropriate Bait available!" instead of "Hold to Select Bait".

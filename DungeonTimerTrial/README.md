# Dungeon Timer: Trials

An add-on for **Dungeon Timer** by @code65536. Dungeon Timer times veteran group dungeons, but it has been retired (last update in 2023) and never supported trials or arenas. This addon adds them.

- **Trials and arenas:** every trial up to Ossein Cage, plus Dragonstar Arena, Maelstrom Arena, Blackrose Prison and Vateshran Hollows.
- **The game's own clock where there is one.** Veteran trials and arenas have a server-side score timer (the one the leaderboards use), and the timer follows it exactly, including after `/reloadui` and when the instance is reset.
- **Starts when the group starts.** Elsewhere the timer starts when you **or any group member in the instance** enters combat, so it starts when the tank pulls, not when you get hit. Fighting in the trial lobby doesn't count.
- **Next to the score display.** In score-tracked content the timer sits right of the game's score / vitality display, and the display moves over if needed so both fit on screen. Elsewhere you can drag the timer anywhere, as before.

## Requirements

- Dungeon Timer

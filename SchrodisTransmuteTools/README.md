# Schrodi's Transmute Tools

Small quality-of-life changes for the transmute station (keyboard UI).

- **Search box** above the item list. Matches item name, trait and set name; several words must all match.
- **Bank toggle** next to it. When off, only the backpack and equipped items are listed. Remembered account-wide.
- **Taller trait list**: all 8 selectable traits fit, no scrolling.
- **"Nirnhoned" in the right-click menu** of weapons of purple quality or lower. One click slots the weapon, selects Nirnhoned and transmutes it. Locked items, items still tradeable within the group and unbound items (transmuting binds them) still get the normal confirmation. The entry is greyed out when the trait isn't researched or you're short on crystals.
- **Crystal count on the Reconstruction tab** (current / cap), next to the tab title. Vanilla only shows it on the Transmute tab.

Requires LibCustomMenu.

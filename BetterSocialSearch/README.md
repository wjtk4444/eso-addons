# Better Social Search

The search box of the **friends list**, **guild roster** and **ignore list** normally only matches account and character names. With this addon it also matches:

- **notes**: find the guildie you wrote "healer, EU evenings" about,
- **zones**: type "Cyrodiil" to see who is in Cyrodiil.

Matching is case-insensitive and finds the text anywhere in the name, note or zone.

Formerly called SearchByNote. If you still have the old `SearchByNote` folder, delete it.
